# System Update Report

This document details the recent improvements and updates made to the application’s infrastructure, covering both the user interface and the geospatial services layer.

## 💻 FRONTEND (User Interface)

A new version of the Frontend has been deployed, focused on optimising the user experience and the display of information.

**Improvements introduced:**
* **Display Optimisation:** Display components have been adjusted to make data interpretation more intuitive and efficient.
* **Performance:** Improved loading times when rendering large volumes of data on the map.
* **Adaptive Interface:** Refinement of visual elements to ensure a consistent presentation of the new data structure.

## 🌍 GEOSERVER

The **GeoServer** service has been successfully updated to reflect the changes made to the master database.

**Update details:**
* **Data synchronisation:** Layers and data stores have been updated following the addition of new records to the database.
* **Metadata Consistency:** The WMS/WFS service descriptors have been reviewed to ensure that the information served is accurate and aligned with the project’s new standards.
